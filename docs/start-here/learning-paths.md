# Learning Paths

Paths link to **areas** for now. As topics are added, list them under each stage so a path becomes a
step-by-step syllabus.

## :material-numeric-1-circle: Foundations — *"I want to use AI well"*

1. [Fundamentals](../fundamentals/index.md) — how models work, prompting and context
2. [LLM Models](../models/index.md) — the main model families and how to choose
3. [Harness Systems](../harnesses/index.md) — pick one assistant or agent tool and learn it properly

**You're done when** you can pick a model and tool for a task and explain why.

## :material-numeric-2-circle: Practitioner — *"I want AI inside my daily work"*

1. [Connectors](../connectors/index.md) — connect your assistant to your docs, code and data
2. [Skills](../skills/index.md) — capture your repeatable tasks as skills
3. [MCP](../mcp/index.md) — understand and add MCP servers
4. [Playbooks](../playbooks/index.md) — run at least one end-to-end workflow

**You're done when** you have one workflow you use every week.

## :material-numeric-3-circle: Builder — *"I want to build and automate"*

1. [MCP](../mcp/index.md) — build your own server
2. [Skills](../skills/index.md) — write, evaluate and share skills
3. [Automation](../automation/index.md) — scheduled, triggered and CI-driven agents
4. [Playbooks](../playbooks/index.md) — document what you built as a playbook

**You're done when** something you built runs on its own and you trust its output.

---

!!! tip "Make your own path"
    Copy one of the sections above, give it a goal and a "you're done when" line, and list the topics
    in order. A path with a clear finish line is far more motivating than a reading list.
