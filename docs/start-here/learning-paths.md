# Learning Paths

Paths link to **areas** for now. As topics are added, list them under each stage so a path becomes a
step-by-step syllabus. Each stage ends with a [Lab](../labs/index.md) so you practise, not just read.

## :material-numeric-1-circle: Foundations — *"I want to use AI well"*

1. [Fundamentals](../fundamentals/index.md) — how models work, prompting and context
2. [LLM Models](../models/index.md) — the main model families and how to choose
3. [AI Products & Apps](../products/index.md) — pick the right app for everyday tasks
4. [Use Cases by Role](../use-cases/index.md) — find the tasks in *your* job AI can help with
5. [Security & Governance](../security/index.md) — the basics of using AI safely

**You're done when** you can pick a model and app for a task, explain why, and know what data not to share.

## :material-numeric-2-circle: Practitioner — *"I want AI inside my daily work"*

1. [Harness Systems](../harnesses/index.md) — learn one agent tool properly
2. [Connectors](../connectors/index.md) — connect it to your docs, code and data
3. [Skills](../skills/index.md) — capture your repeatable tasks as skills
4. [MCP](../mcp/index.md) — understand and add MCP servers
5. [Multimodal](../multimodal/index.md) — work with PDFs, images and voice
6. [Playbooks](../playbooks/index.md) — run at least one end-to-end workflow

**You're done when** you have one AI workflow you use every week.

## :material-numeric-3-circle: Builder — *"I want to build and automate"*

1. [Building with LLM APIs](../apis/index.md) — call models and build agents from code
2. [RAG & Knowledge](../rag/index.md) — ground your system in your own data
3. [MCP](../mcp/index.md) — build your own server
4. [Evaluation & Observability](../evals/index.md) — prove it works and catch regressions
5. [Security & Governance](../security/index.md) — permissions, injection and secrets for real systems
6. [Automation](../automation/index.md) — scheduled, triggered and CI-driven agents
7. [Customization](../customization/index.md) — *optional:* fine-tuning and self-hosting

**You're done when** something you built runs on its own, has an eval, and you trust its output.

## :material-radar: Ongoing — *"I want to keep up"*

- Skim the [AI Radar](../radar/index.md) regularly and add a dated note for anything that matters to you.
- When a radar item reaches **trial**, try it in a [Lab](../labs/index.md); when it reaches **adopt**, write it up
  as a full topic in its area.
- Review topics flagged :material-alert: in the [catalog](../resources/catalog.md).

---

!!! tip "Make your own path"
    Copy one of the sections above, give it a goal and a "you're done when" line, and list the topics
    in order. A path with a clear finish line is far more motivating than a reading list.
