## How this hub works

<div class="grid two" markdown>

!!! info ":material-map-marker-path: Learn"
    Follow a [learning path](start-here/learning-paths.md), or jump straight into any area.
    Every topic has the same shape: **TL;DR → concepts → hands-on → practical applications → checklist**.

!!! success ":material-hammer-wrench: Apply"
    Each topic ends with real use cases and a checklist. [Playbooks](playbooks/index.md) stitch
    topics together into complete, repeatable workflows.

!!! tip ":material-update: Update"
    Topics carry a **status** and a **last reviewed** date. Anything older than six months is
    flagged for review, so stale knowledge is easy to spot.

!!! example ":material-magnify: Find"
    Use search (++slash++), the [topic catalog](resources/catalog.md), [tags](resources/tags.md)
    or the [glossary](resources/glossary.md).

</div>
